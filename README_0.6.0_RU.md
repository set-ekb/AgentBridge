# AgentBridge 0.6.0 — многомодельный агент с голосом (исходный код)

**Статус:** исходный код изменён на основе 0.5.5. APK 0.6.0 в этой среде не собирался: отсутствует Android SDK/Gradle, доступа к серверам загрузки нет. Прямые запросы к реальным OpenAI, Anthropic, Gemini и тест на телефоне НЕ проводились. `VALIDATION.json` в исходном архиве относится только к версии 0.5.5.

## Возможности

- Один интерфейс управления Android с четырьмя вариантами ИИ:
  - Gemini — `generativelanguage.googleapis.com/v1beta` (с существующим механизмом повторов для ошибок 429).
  - OpenAI — `api.openai.com/v1/responses` и вызовы функций (нужен отдельный API-ключ, подписка ChatGPT Plus сама по себе не является API-ключом).
  - Claude — `api.anthropic.com/v1/messages` и `tool_use/tool_result` (нужен отдельный API-ключ Anthropic).
  - Совместимый OpenAI Chat Completions — произвольный `https://.../chat/completions` или HTTP на **этом же телефоне** `http://127.0.0.1:PORT/v1/chat/completions` (сервис обязан поддерживать `tools`, обычный chat endpoint без tools не подойдёт).
- Все провайдеры используют **один набор защищённых инструментов** AgentBridge. Провайдер не получает произвольный root/shell.
- Ключи каждого провайдера раздельно хранятся через Android Keystore (используется исходный AES-GCM key alias для обратной совместимости Gemini).
- Пользовательские знания (до 6000 символов) сохраняются в SharedPreferences; базовый профиль содержит данные об устройстве и безопасные правила навигации. Системный контекст дополняется реальными свойствами Android через `Build` и текущим проверенным пакетом приложения.
- Короткие пары вопрос–результат (4 последних) сохраняются **только в памяти процесса**, не включают сырые деревья Accessibility и общие между сменами провайдера. Кнопка очистки диалога.
- Голос: Android `RecognizerIntent` распознаёт команду; после распознавания задание запускается, а завершение озвучивается через Android TextToSpeech. Это **пошаговый голосовой диалог с нажатием кнопки микрофона**, не непрерывный hands-free/always-listening.
- Рутинные действия обычно проходят **без подтверждений**; нажатия на явно опасные элементы (оплата, удаление и т.п.) по текстовой эвристике требуют подтверждения. Этот фильтр НЕ гарантирует распознавание всех рискованных действий: непрозрачные элементы интерфейса и иные способы нажатия могут обходить эвристику. В настройках можно вернуть подтверждение каждого действия. Stop по-прежнему работает.

## После сборки и установки

1. Открой AgentBridge, включи Accessibility.
2. В панели выбери провайдера, введи индивидуальный API-ключ (для локального совместимого API он может быть пустым), впиши **идентификатор модели**, а для совместимого API — полный URL.
3. Проверь/измени поле **Знания агента**, нажми «Сохранить знания».
4. Для голосового управления нажми `🎤 Сказать задачу и выполнить` и произнеси команду по-русски. При необходимости во время задержки перейди в целевое приложение. Агент выполняет задачи через Accessibility и произносит итог.
5. Для ручного режима введи команду текстом и нажми «Выполнить задачу».

## Сборка

Понадобятся JDK 17, Android SDK Platform 35 и Build Tools 35.0.0, Gradle 8.9, доступ к Maven Central/Google Maven и Android Gradle Plugin 8.7.3. В корне проекта:

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

Для установки на телефон используйте собранный `app/build/outputs/apk/debug/app-debug.apk`. При обновлении поверх предыдущего установленного APK потребуется совпадающая подпись; debug APK, скорее всего, не совпадёт с прежней release-подписью. **Не удаляйте установленную рабочую версию без резервного копирования настроек и ключей:** Android Keystore-ключи могут быть потеряны при переустановке. Для установки поверх 0.5.5 подписывайте новой сборке тем же прежним ключом.

## Что обязательно проверить на устройстве

1. 0.5.5 Gemini: чтение экрана + один безопасный `launch_app`, поведение при квоте 429.
2. OpenAI: вызов read-only инструмента; затем подтверждённый `tap_node` по безопасному элементу и чтение нового экрана.
3. Anthropic: такой же тест и цикл нескольких последовательных `tool_use/tool_result`.
4. Совместимый API: схема `tools` и необходимость корректного формирования `tool_calls`.
5. Голосовое распознавание с русской локалью; TTS в фоне и при переключении в другое приложение.
6. Защита от повторов, доступность кнопки «Остановить», корректный возврат из ApprovalOverlay; отсутствие запросов на подтверждение обычных действий.
7. Безопасность: не отправлять платежи/удаления без явного разрешения, не пересылать коды/секреты модели; не загружать личную переписку без надобности.

## Текущие ограничения

- Поставщики OpenAI/Anthropic не имеют встроенного листинга моделей; ID задаётся вручную.
- Автопродолжения задачи после смены модели **в середине операции** пока нет: переключение влияет на следующий запуск.
- Нет автономного wake-word, потоковой аудиобеседы, фонового прослушивания микрофона и офлайн-распознавания «по гарантии». Доступность речи зависит от службы Android.
- Мульти-модельный режим, новые вызовы API, эвристика подтверждений и голосовая часть требуют тестирования. Не считайте исходники стабильной рабочей APK.
