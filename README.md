# AgentBridge

Универсальный Android-агент с управлением телефоном, общим контекстом и памятью,
текстовым и голосовым диалогом, а также поддержкой **Gemini, OpenAI, Claude**
и OpenAI-совместимых моделей.

**Разработка и сопровождение: [set-ekb](https://github.com/set-ekb).** При использовании
проекта, пожалуйста, указывайте автора/сопровождающего и ссылку на этот репозиторий.
Правила распространения исходного кода определяются существующей лицензией [MIT](LICENSE)
(исходное уведомление об авторских правах Pluginslab сохранено).

## Почему проект открыт

> «Делай добро и бросай его в море — оно добром тебе вернётся».

Мы публикуем AgentBridge в открытом доступе, чтобы результат нашей работы мог
пригодиться другим. Если проект поможет кому-то решить свою задачу, научиться
новому или создать что-то своё — значит, мы делали это не зря.

Пользуйтесь, изучайте, улучшайте и делитесь. Будем рады упоминанию
[set-ekb](https://github.com/set-ekb) и ссылке на проект; юридические условия
использования и распространения определяет [лицензия MIT](LICENSE).

## Текущий выпуск: 0.8.5-local · REVIEW

Это открытая исходная база для развития проекта. Выполнены автоматизированные
проверки (91 JVM-тест, сборка Debug APK, Android lint: 0 ошибок / 70 предупреждений),
но полноценная проверка **на телефоне и с реальными API** ещё не завершена.
Нельзя считать это гарантирующей стабильность release-сборкой.

Проект поддерживает локальную память и перенос контекста между провайдерами,
диалог в процессе исполнения задач, виджет/уведомления, управление задачами
(пауза, продолжение, стоп) и общую очередь с учётом квот API.

## Сборка

Необходимы **JDK 17**, **Android SDK 35** и Gradle wrapper из репозитория.

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

Устанавливаемый APK в исходный репозиторий не включён. Подписанные сборки публикуются
в [GitHub Releases](https://github.com/set-ekb/AgentBridge/releases/latest),
когда владелец настроит постоянный закрытый ключ в GitHub Actions.

**Постоянная ссылка на APK после первого подписанного выпуска:**
https://github.com/set-ekb/AgentBridge/releases/latest/download/AgentBridge.apk

**Настройка подписи и миграция с прежних debug APK:** [docs/SIGNING_RU.md](docs/SIGNING_RU.md).
Не удаляйте текущую версию до экспорта памяти и резервного копирования настроек.
