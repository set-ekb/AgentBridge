# AgentBridge 0.7.0 — общая память, модели и голос

Персональная Android-сборка: com.pluginslab.agentbridge, versionCode 20.
Основа — исходники 0.6.0 с перенесёнными правилами 0.5.7. Это первая реализация основных частей архитектуры 0.7, не завершение всех её пунктов.

## Что доступно

- Четыре вкладки: «Агент», «Память», «Настройки», «Журнал». Стоп остаётся над вкладками и в уведомлении.
- Провайдеры: Google Gemini, OpenAI Responses, Anthropic Messages, совместимый Chat Completions API. Профили и ключи раздельные. Модели выбираются пользователем; список загружается для Gemini, остальные ID вводятся вручную.
- «Проверить соединение» отправляет короткий текстовый запрос без каталога инструментов. Действия на телефоне для теста не выполняются.
- Кнопка микрофона: системное русское распознавание → текст задачи → запуск. Итог и ошибки могут озвучиваться Android TTS. Есть настройки высоты (по умолчанию 1.1) и скорости. Стоп прекращает озвучивание и запрещает дальнейшие действия.
- Общая зашифрованная SQLite-база памяти, независимая от провайдера: базовые знания, факты приложений, сценарии, эпизоды и импортированные тексты.
- Поиск по всем сохранённым записям (до 1000), редактирование, удаление, закрепление, статус подтверждения, источник, область и ревизия. Поле «Личные данные» исключает запись из экспорта; разрешение передачи в облако настраивается отдельно.
- Поиск релевантного контекста без векторной базы: ключевые слова задания, категория, активный пакет, закрепление и свежесть. Контекст ограничен примерно 12000 символами, большая закреплённая запись сокращается с пометкой. Подтверждённые локальные записи не отправляются в облако. Только совместимый endpoint с точным loopback-адресом считается локальным; HTTPS в домашней сети консервативно считается облаком.
- Технический факт наблюдения активного package name может сохраняться автоматически по успешному инструментальному наблюдению. Исправления владельца этой записи не перезаписываются наблюдателем. Сырые деревья, экраны и переписки автоматически в базу памяти не копируются. Универсальные сценарии пока добавляет и проверяет владелец.
- Импорт .md/.txt и собственного JSON-экспорта: предпросмотр, затем непроверенные записи с запрещённой передачей в облако. Для использования откройте запись, проверьте её и настройте доступ. Ограничение импорта 256 КБ, до 100 записей; одна запись до 12000 символов. Произвольный JSON другого формата не поддерживается.
- Экспорт JSON через системное сохранение файла: исключаются личные, локальные записи и распознанные секреты. Такой фильтр не гарантирует распознавание любого секрета в свободном тексте; перед распространением проверьте содержимое. Ключи API и задачи не включаются в этот экспорт.
- Зашифрованные контрольные точки задач до/после инструментов, отдельный технический журнал без экранных текстов. Сохраняется до 30 задач и 300 технических событий; на экране показаны 8 последних задач и 100 событий. Подробный сырой журнал текущей задачи остаётся только в RAM.
- Продолжение прерванной задачи из вкладки «Агент» с выбранной моделью: нейтральная карточка состояния и свежий экран, без переноса сырых провайдерских thought signatures. При неизвестном эффекте прошлого действия агенту запрещено повторять его вслепую.
- Нажатие само по себе не считается выполненной задачей: перед итогом после изменений требуется пригодное свежее дерево UI. Это минимальная техническая проверка; смысл и соответствие цели оценивает модель, поэтому ошибки модели всё ещё возможны.
- 429/временные ошибки: повторяется сетевой запрос с той же историей, а не Android-действия. Остановка прерывает ожидание. Подтверждённая дневная квота Gemini и известные ошибки биллинга OpenAI не повторяются. Для остальных API учитывается Retry-After и ограниченный бюджет ожидания.
- Автоматического переключения между провайдерами нет. По ранее заданному владельцем режиму обычные действия выполняются без окон подтверждения. Сохраняются проверки актуальности окна/узла, доступных инструментов, повторных нажатий и границ задания.

## Обновление

Устанавливать APK поверх персональной 0.5.x; удалять приложение не требуется.
Сертификат SHA256:
7c647f03e0bf659557deb182c609ebf6419466b98daa607c793be3a0e068e775

Ключ Gemini и другие провайдерские ключи сохраняют прежние имена и Keystore alias.
Заметки из 0.5.7 (зашифрованные) или 0.6 (старое поле) переносятся в зашифрованную запись базы. Старая заметка удаляется из настроек только после успешной записи в БД. Пустая сохранённая память не заменяется стартовой.
Старое поле текста задачи также переносится в зашифрованное хранение.
При ошибке чтения или миграции приложение показывает ошибку и не сбрасывает сохранённую память.

Восстановление после убийства процесса не автоматическое: откройте Агент, выберите задачу и нажмите «Продолжить с текущей моделью». При смене провайдера такая кнопка передаёт цель и краткое состояние выбранному API. Старые ID узлов не переиспользуются.
В настройках другого провайдера нужны соответствующие API-ключ и модель; подписка ChatGPT/Claude не заменяет API-биллинг.

## Что проверить на телефоне

1. Установить поверх 0.5.7, открыть «Память»: прежние заметки на месте; Gemini-ключ не запрашивается заново.
2. Создать запись, закрыть приложение и открыть снова: запись остаётся. Удалённая запись не возвращается.
3. Задать «Прочитай название активного приложения, ничего не нажимай»; проверить реальный ответ и журнал.
4. Открыть другое приложение через агента; убедиться в свежем чтении экрана и корректном итоге.
5. Прервать задачу, перезапустить приложение, продолжить с выбранной моделью: сначала проверяется текущий экран.
6. Проверить микрофон и TTS на установленной службе Android, затем Стоп во время озвучивания.
7. Импортировать обычную заметку: она остаётся pending и local-only до проверки владельцем. Проверить экспорт через системный диалог.
8. При наличии API-ключей проверить каждого провайдера сначала кнопкой соединения, затем простой задачей чтения.

## Границы первой итерации

Нет облачной синхронизации, FTS/векторного поиска, непрерывного прослушивания, голосового wake word, автоматического изучения произвольных сценариев и полного валидатора высокорисковых намерений. Никакой произвольный root/shell не выдаётся встроенной модели.
SQLite-поля записей и задач защищены AES-GCM через Keystore; это не обещание абсолютной защиты рутованного устройства. Метаданные таблиц и наличие записей остаются видимыми.
Свежий экран после действия даёт свидетельство, а не автоматическое доказательство достижения бизнес-цели.

## Проверки сборки

JDK 17, Gradle 8.9, Android SDK 35. Зависимости берутся из подготовленного кэша; новых библиотек базы данных не добавлено.

```bash
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

Тесты проверяют выборку/приватность памяти, импорт/экспорт, модель контрольной точки, три формата tool calls, повтор запросов и прежние навигационные защиты. Android Keystore, SQLite-миграция, внешний API, микрофон, TTS и UI требуют проверки на телефоне: локальные JVM-тесты их не заменяют.
Архив исходников не содержит закрытый ключ подписи, API-ключи, локальный SDK или сборочные каталоги.
