# AgentBridge 0.5.5-local — встроенная панель Gemini

Персональная версия на основе pluginslab/android-agent-bridge (MIT).

## Исправления 0.5.5

- HTTP 429 больше не заканчивается только короткими повторами через 3 и 6 секунд. Учитываются Retry-After (секунды или HTTP-дата) и google.rpc.RetryInfo.retryDelay с запасом 1 с; выбирается большее значение. Если подсказки отсутствуют/некорректны, начальная пауза 65 + 1 с с последующим увеличением. Максимум четыре повтора и суммарно 5 минут ожидания на один API-запрос, в пределах общего 15-минутного времени задачи.
- Подтверждённая суточная квота или нулевая quotaValue не вызывают ожидание и повтор. HTTP 503 повторяется до трёх раз с увеличением пауз. Ожидание показывает обратный отсчёт, отменяется кнопкой остановки; модель и API-ключ автоматически не переключаются.
- Повторяется только тот же запрос генерации с теми же contents, functionResponse и thoughtSignature. Уже исполненные инструменты заново не вызываются. Повтор не расходует новый шаг модели. Продолжение работает, пока процесс жив: восстановление после выгрузки приложения не добавлено.
- Повторное нажатие той же кнопки при неизменном снимке экрана отклоняется до подтверждения. ACTION_CLICK подтверждает отправку события, а не изменение состояния приложения. Для неоднозначного результата агенту предлагается одно чтение активного окна с глубиной 40; автоматического повторного изменения или координатного клика нет.
- Счётчик повторных чтений исключает render_wait_ms из сравнения: разное время загрузки больше не маскирует одинаковые результаты.
- Уточнены инструкции поиска названного приложения и выбора между профилями с одинаковым именем по реально отображаемому целевому устройству. В код не зашиты имена детей, адреса аккаунтов или идентификаторы устройств.
- Предыдущий журнал подтвердил достижение нужного телефона, но не добавление часа. 0.5.5 проверяется локально с имитацией ответов API; успех операции Family Link и снятие квоты на реальном проекте не заявляются.

## Исправления 0.5.4

- Встроенный агент не может нажать пустую заглушку загрузки без подписи, описания или понятного назначения. Подписанные кнопки, составные кнопки с текстом в дочернем элементе и поля ввода доступны. Проверка выполняется до запроса подтверждения; внешний MCP не меняется.
- Перед действием узел обновляется через accessibility refresh и сверяется с метаданными снимка: смена текста, описания, размеров или назначения требует нового поиска.
- get_ui_tree внутри локального агента ждёт стабилизации подписанного содержимого (минимум 750 мс, стабильность 500 мс, предел 3 с). Если список окон не содержит семантики активного приложения, автоматически читается его активное окно. Ожидание ограничено и не гарантирует завершения сетевой загрузки: пустые узлы всё равно нельзя нажимать, а при незавершённом ожидании возвращается loading_hint.
- Бюджет расширен до 32 ответов модели и 64 инструментов. Последние два ответа и два вызова отведены для чтения результата и отчёта; новые действия в этот период отклоняются. Лимит 15 минут и защита от повторов сохранены.
- В задачах экранного времени просьба «добавить час» трактуется как разовый бонус на сегодня. Агент должен проверить ребёнка/устройство, выбрать подписанное действие, сохранить изменение и подтвердить результат чтением интерфейса; постоянные лимиты не меняются без запроса.
- Успех предыдущей версии 0.5.3 подтверждён владельцем на телефоне: возврат из открытого письма, распознавание действующего поиска Gmail и прокрутка с проверкой смены строк. Сценарий Family Link выявил отдельную проблему: нажатие пустого блока во время загрузки и исчерпание 20 ответов; добавление времени в присланном журнале не подтверждено.
- Для 0.5.4 требуется проверка выполнения полезной задачи на телефоне; локальные проверки не подтверждают, что час уже добавлен.

## Исправления 0.5.3

- При запуске приложение может восстановить детальный экран или прокрученный список. Инструкция агенту теперь требует сначала определить текущее состояние; для возврата внутри приложения предпочитать видимую кнопку «Перейти вверх»/«Назад».
- Скрывшиеся поля ввода возвращаются с hidden_editable_fields и указанием положения, включая above_or_collapsed. Агент получает подсказку раскрыть верхнюю панель свайпом и найти видимый узел заново.
- Дерево отмечает скрытые/обрезанные реальные узлы [offscreen], результаты поиска содержат visible. Неположительные размеры считаются недоступными для нажатия.
- Встроенный агент не предлагает tap_coords: у него нет проверки по изображению, поэтому свободные координатные клики заменены поиском реальных узлов. Свайпы и внешний MCP сохранены.
- Перед кликом/вводом по node_id проверяется существование и доступность узла. Скрытый или устаревший узел возвращает подсказку без выполнения действия.
- Счётчик повторных чтений сравнивает экран и результат для того же запроса. После изменения экрана или результата отсчёт начинается заново. При втором одинаковом чтении выдаётся recovery_hint, при пятом задача останавливается с объяснением, что агент не продвинулся.
- Если нужный поиск уже активен, агенту предложено выполнить только оставшиеся шаги задачи.
- Добавлены регрессионные тесты для скрытой строки поиска с высотой -165 и счётчика, который ошибочно срабатывал после смены экрана.

## Улучшения 0.5.2

- Активный пакет определяется до первого запроса Gemini и передаётся как служебный контекст.
- Перед поиском и действиями по интерфейсу панель сама проверяет текущий пакет.
- Чтение собственной панели отклоняется с подсказкой открыть целевое приложение; текст задачи больше не принимается за поле поиска Gmail.
- После неожиданной смены приложения требуется проверить новый контекст через get_active_window_info или открыть целевое приложение заново.
- resource_id для поиска/ожидания допускается после наблюдения в реальном AccessibilityNodeInfo данного приложения. Проверка использует метаданные узлов, а не текст страницы или задачи.
- Неизвестный resource_id возвращает ошибку сразу, без ожидания тайм-аута. Можно выполнить поиск по тексту/описанию/editable или прочитать дерево.
- Журнал указывает active_package и guard_rejected для отклонённых проверок.
- Добавлены регрессионные тесты для ложного совпадения с текстом задачи, угаданного ID и смены приложения.

## Исправления 0.5.1

- Запуск из видимой панели выполняется через её Activity в главном потоке.
- launch_app ждёт до 8 секунд и сообщает success=true / verified=true только после появления окна нужного пакета.
- Если команда отправлена, но окно не появилось, результат содержит isError=true, текущий пакет и контекст запуска. Встроенный агент останавливает задачу и не выдаёт ложное сообщение об успешном открытии.
- Причина возможного отказа Android не угадывается по одному результату.
- Длинные надписи кнопок больше не обрезаются фиксированной высотой.
- Добавлены тесты для случая, когда после команды Gmail активным остался AgentBridge.

## Что добавлено

- Русская панель открывается по иконке AgentBridge.
- Ключ Gemini хранится зашифрованным с ключом Android Keystore.
- Список моделей запрашивается через ваш API-ключ; можно ввести имя модели вручную.
- Задачи, настоящая задержка старта 0–30 секунд, статус и журнал результатов.
- Выполнение в foreground-службе; остановка из панели и постоянного уведомления.
- Каждое действие требует подтверждения в наложении поверх управляемого приложения.
- Перед действием проверяется, что активное окно не сменилось; для нажатий и ввода дополнительно сравнивается содержимое экрана.
- Проверка списка приложений без Gemini и без расхода API-квоты.
- QUERY_ALL_PACKAGES и обычная, адаптивная, монохромная иконки.
- Существующий внешний MCP и его настройки сохранены.

Встроенной панели не требуются Termux, Python, токен MCP или запущенный MCP-сервер.
Панель и MCP используют одни и те же реализации инструментов.

## Установка

Пакет: com.pluginslab.agentbridge. versionCode: 12.
Подпись совпадает с нашей предыдущей персональной сборкой 0.4.2-app-visibility:
SHA256 сертификата 7c647f03e0bf659557deb182c609ebf6419466b98daa607c793be3a0e068e775.
Её и персональные версии 0.5.0/0.5.1/0.5.2 можно обновить без удаления. Исходный APK разработчика подписан другим ключом:
для перехода с него потребуется переустановка со сбросом настроек AgentBridge.
Удаление AgentBridge не удаляет Gmail или его данные.

## Первый запуск

1. Откройте AgentBridge и включите его службу спецвозможностей.
2. Нажмите «Проверить список приложений · без Gemini». Проверьте наличие Gmail.
3. Введите и сохраните API-ключ Gemini (это не токен Bridge).
4. Нажмите «Загрузить и выбрать модель» и выберите доступную текстовую модель с инструментами.
5. Для первого теста оставьте задержку 5 секунд и задачу «Прочитай название активного приложения. Ничего не нажимай.».
6. Разрешите уведомления, нажмите запуск ещё раз, перейдите в Gmail во время отсчёта.
7. Вернитесь в панель и посмотрите результат. Журнал можно раскрыть или скопировать.
8. Следующая проверка: поручить найти Gmail и открыть его; подтвердить launch_app поверх текущего экрана.

Ключ из Termux автоматически не переносится: его нужно ввести один раз в новой панели.
Нельзя одновременно запускать две задачи. При смене экрана во время подтверждения
действие отменяется. Уже выполненные действия остановка не отменяет.

## Данные и ограничения

Текст задачи и ответы инструментов, включая содержимое интерфейса, отправляются в Gemini API.
Ключ не сохраняется в открытом виде и не заполняется в поле после сохранения.
Журнал и результат хранятся в памяти процесса; текст задачи и модель сохраняются локально.
Скопированный журнал может содержать личные данные с экрана — просмотрите перед пересылкой.
Модели с генерацией изображений/озвучкой могут не поддерживать инструменты.
429 означает лимит API; панель показывает имя лимита, если Google вернул его в структурированных деталях. Минутные и неуточнённые временные ограничения ожидаются с ограниченными повторами; при подтверждённом дневном лимите ожидание не начинается.
Максимум 32 ответа модели, 64 вызова (с резервом на проверку и отчёт), 15 минут на задачу; подтверждение ждёт до 2 минут.
Полные ответы модели со служебными подписями возвращаются API без потери thoughtSignature.

Локальный агент использует чтение UI, поиск приложений, запуск, нажатия, прокрутку и ввод.
Произвольные скрипты, cookie-инструменты и send_intent не передаются модели.
Внешний MCP сохраняет оригинальный набор инструментов.
Проверку на реальном телефоне и с настоящим API-ключом должен завершить владелец:
эти проверки нельзя заменить успешной компиляцией или локальными тестами.

## Исходники и сборка

JDK 17, Gradle 8.9, Android SDK Platform 35, build-tools 35.0.0.
Укажите собственный SDK в local.properties либо ANDROID_HOME.

    ./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug

Для обновлений используйте персональный ключ из сохранённого
AgentBridge-local-build-backup.zip. Не публикуйте закрытый ключ.
Обычная Gradle debug-сборка использует другой ключ; APK для установки нужно
подписать персональным ключом через apksigner.

На ARM/Termux может потребоваться локальный ARM aapt2; см. оригинальный README.
Подробности реализации: agent/* и server/tools/LocalTools.kt.
