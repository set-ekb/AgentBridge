# AgentBridge 0.8.4 — диагностика Vector/Xposed и работы агента

## Что изменилось

Журнал `diagnostics.jsonl` теперь объединяет технические события:

- `ui_event` — изменения окон Accessibility;
- `hook_event` — принятые сигналы `resumed`/`paused` из Hooks (могут быть подделаны сторонним приложением);
- `hook_status` — получен первый сигнал `hook_active`;
- `hook_error` — приёмник отклонил невалидное сообщение;
- `api_request`/`api_response`/`api_error`, `tool_start`/`tool_finish`, `task_start`/`task_finish`/`task_error`;
- `phase` и `app_error` — жизненный цикл сервисов и категории необработанных ошибок.

Записи сохраняются между запусками. Ограничение на размер — 768 КБ, ротация
с сохранением целых строк. В каждом событии время, монотонное время,
источник, тип, безопасный статус, при наличии имя пакета/Activity, длительность
и номер шага. Ни тексты диалогов, ни деревья UI, ни тела HTTP, ни API-ключи,
ни полные тексты исключений в этот JSONL не записываются.

В AgentBridge → **Журнал → Обновить диагностику хуков** показываются последние
сохранённые события Hooks независимо от шума Accessibility. Кнопка
**Экспорт диагностики (.jsonl)** выдаёт единый полный журнал с заголовком схемы v2.

## Логи непосредственно в Vector

*Важно:* если Xposed-модуль не загрузился, он **не может** прислать сообщение
в AgentBridge. Поэтому сам модуль через API `XposedModule.log()` пишет
следующие этапы в журнал Vector/LSPosed под тегом `AgentBridgeHooks`:

| Сообщение Vector | Значение |
| --- | --- |
| `module_loaded` | Vector создал экземпляр модуля. |
| `package_ready` | Колбэк выбранного пакета запущен. |
| `hooks_installed` | Установка перехватчиков прошла без синхронного исключения. |
| `first_callback` | Перехватчик Activity впервые выполнился. |
| `hook_install_failed` | Ошибка установки; указан только класс исключения. |
| `dispatch_failed` | Ошибка отправки сигнала в AgentBridge. |

При первом колбэке модуль также отправляет диагностическое событие
`hook_active`, которое AgentBridge записывает как
`hook_status · callback_active`. Далее приходят `hook_event` для
`resumed` и `paused`. Сам факт получения сигнала — **не подтверждение**
правильной работы Android UI или успешности команды агента.

## Проверка на телефоне

1. Обновите **основной AgentBridge 0.8.4** и **AgentBridge Hooks 0.3** (оба APK).
   Подпись GitHub Releases должна совпасть с ранее установленной 0.8.3.
   **Не удаляйте** приложение с памятью и ключами.
2. В Vector разрешите модулю только **Настройки** `com.android.settings`.
   Сам AgentBridge не нужен в scope (код модуля его пропускает).
3. Перезапустите процесс «Настройки» и откройте несколько разделов.
4. В Vector → Журналы найдите `AgentBridgeHooks` и события выше.
5. В AgentBridge → Журнал → Обновить диагностику хуков проверьте
   `hook_status`/`hook_event`, выгрузите `agentbridge-diagnostics.jsonl`.
6. Если событий нет, сообщите *последнюю достигнутую стадию в Vector*
   (`module_loaded`, `package_ready`, `hooks_installed` или ни одной).

Тест `am broadcast` с правами root проверяет **только приёмник**. Полученный
из него `vector_hint` не доказывает, что Xposed-хук действительно запускался.
При необходимости используйте реальный журнал Vector и выборочный `logcat`
по тегу `AgentBridgeHooks`.

## Границы версии

0.8.4 — **диагностическая итерация**, не финал всего roadmap Issue #3.
Полная корреляция `task_id/action_id` и событий Android, измерение ускорения,
отладка старых дублей и управление scopes остаются отдельными задачами. Не
разрешать команды агента на основании одних сигналов от Vector.


## Передать журнал помощнику (AgentBridge 0.8.5)

Новая кнопка **«Сохранить журнал с датой (.jsonl)»** открывает стандартный
Android-диалог выбора папки и предлагает имя с локальной датой и временем
вида `AgentBridge-log-2026-10-21_00-15-30.jsonl`.
Так выгрузки за разные сеансы не перезаписывают друг друга.

Кнопка **«Поделиться журналом с помощником»** создаёт только временную
копию в защищённом кэше AgentBridge и открывает стандартное меню Android
**«Поделиться»**. Файл не отправляется в интернет автоматически, право
чтения выдаётся только выбранному приложению. Старые временные копии
при следующем экспорте удаляются спустя сутки.

Если в списке получателей есть ChatGPT и он поддерживает приём файла,
выберите его. Если ChatGPT не отображается или получил только текст,
сохраните журнал первой кнопкой, затем откройте нужный разговор ChatGPT,
нажмите **«+» / скрепку → Файлы** и прикрепите сохранённый `.jsonl`.
Это ручное прикрепление файла к разговору — **не** автоматический доступ
моделей AgentBridge к журналам. Для встроенного агента отдельный
локальный диагностический инструмент можно проектировать независимо.

Перед отправкой проверьте файл: хотя тексты экранов и токены исключены,
названия пакетов приложений и временные метки могут раскрывать активность
на устройстве. Ничего не отправляется без действия владельца.
